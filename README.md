# [🎵 Musical Bingo](https://musicalbingo.onrender.com/)

Digitalización del bingo musical, con pistas de Spotify.

Tachá las canciones y cantá **¡BINGO!**

---

## 🎮 Cómo Jugar

### Objetivo
Completar los patrones requeridos en tu cartón virtual antes que los demás jugadores, basándote en las canciones que se van reproduciendo.

### Mecánica del Juego

1. **El DJ Deck**: La música es aleatoria
2. **Escucha y Identifica**: Cuando suene una canción, revisá tu cartón. Si la canción coincide con algo tu cartón, ¡tachalo!
3. **Patrones Ganadores**: Podes ganar completando:
   - **Línea**: Una fila horizontal completa.
   - **Cartón Lleno**: Todas las casillas del cartón.
   - **Patrones Especiales**: Cruces, esquinas, o patrones personalizados creados por el host.
4. **Cantar Bingo**: Cuando completes un patrón, el sistema detectará tu victoria y activará el modo celebración neón para todos.
5. **Revision del ganador**: Cuando alguien dice bingo se decide si efectivamente ganó o no.

## ✨ Características

### 🌈 Estética Neon Overhaul
- **Dark Mode & Glassmorphism**: Una interfaz moderna con efectos de cristal y fondo violeta profundo.
- **Glow Effects**: Celdas que brillan al seleccionarlas y botones con aura de neón.
- **Animaciones Dinámicas**: Disco de vinilo giratorio para el DJ y ondas de sonido reactivas.

### 🎵 Integración con Spotify
- **Reproductor Real**: Escucha clips de 30 segundos directamente en la app.
- **Autoplay**: La música fluye automáticamente al pasar a la siguiente canción.

### 🛠️ Configuración Avanzada para el DJ
- **Géneros Personalizables**: Elige entre Rock, Pop, Jazz, Reggaeton, Música Clásica y más.
- **Editor de Patrones**: Crea tus propios diseños de victoria (ej. una "X" o un cuadrado).
- **Tamaño de Grilla**: Configura cartones desde 3x3 hasta 8x8.

### 🌐 Conectividad
- **Salas Privadas**: Crea una sala y comparte el código de 4 letras.
- **Juego LAN**: Detecta automáticamente partidas en tu misma red WiFi.

## 🚀 Instalación (Desarrolladores)

### Requisitos
- [Node.js](https://nodejs.org/) (v18 o superior)

### Pasos para empezar

1. **Clonar el repositorio**:
   ```bash
   git clone https://github.com/gabrielfranicevich/musical_bingo.git
   cd musical_bingo
   ```

2. **Instalar dependencias**:
   ```bash
   npm install
   ```

3. **Modo Desarrollo**:
   ```bash
   npm run dev
   ```
   Inicia en `http://localhost:5173`

4. **Construir para Producción**:
   ```bash
   npm run build
   ```
